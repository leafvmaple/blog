# 在 Godot 2D 管线上堆出 HD-2D

HD-2D——等距像素世界叠上现代后处理与动态光照,Octopath Traveler / Triangle Strategy 那一脉——的难点不在每个效果本身,而在 Godot 4 的 gl_compatibility 2D 后端上怎么把它们落地。两条硬约束塑造了整套管线的形状:**跨 CanvasLayer 的屏幕读取在该后端返回纯白**;**任何精灵挂上自定义材质,会在受光画布里恒定地暗约一成**。前者决定了后处理只能怎么接,后者反复出现在轮廓光、电影分级、精灵提亮三处。

![实机成片:稻香村,全效果叠满](https://code.leafvmaple.com/assets/hd2d/hero.gif)

上面是实机成片(稻香村,效果全开:暮色调 + 暗角 + 距离雾 + 结构/角色投影 + 轮廓光 + 辉光 + 大气落叶)。下面各节会用「裸基线 vs 单加该技术」的对比图把每一层拆开看——从渲染底座往上,依次是屏幕后处理、光与影、自定义材质的怪癖、时段大气,最后是这条路还能往哪走。

## 一、底座只能是 SubViewport

第一反应是把后处理 shader 直接挂在一个盖住全屏的 `ColorRect` 上、用 `screen_texture` 采样已经画好的世界。这在 Forward+ 下可行，在 gl_compatibility 下不行——**跨 CanvasLayer 的屏幕读取在该后端返回纯白**。

可靠的做法是把整个游戏世界(场景/大地图/战斗/标题)渲进一个 `SubViewport`，后处理 shader 挂在装它的 `SubViewportContainer` 上、采那张真实的 viewport 纹理。HUD 和弹窗留在 SubViewport 外面,因此永远不过后处理、保持清晰锐利。

这个 SubViewport 还顺手解决了「任意画质」:它按**物理窗口分辨率**渲染(下限 1280×800),同时用 `size_2d_override` 把 2D **逻辑坐标**钉死在原逻辑尺寸——相机、zoom、取景的代码全不动,只有渲染分辨率随窗口拉高。放大窗口得到的是更清晰、而非更大的视野。容器再按渲染分辨率反向缩放、贴回同一块逻辑布局区,和被「提」到外面的 UI 对齐。等距像素游戏因此能脱离当年那种锁死的低分辨率,而瓦片与精灵的对齐逻辑一行不改。

这一层之后承载了一整摞屏幕级效果,全在 `hd2d_post.gdshader` 里,一遍 fragment 走完:曝光/饱和/对比、冷暗部暖高光的分离色调、辉光、移轴景深、暗角、色差、抖动、胶片颗粒、3D LUT 查表、距离雾。数值由 `hd2d.json` 覆盖,不写就用引擎默认。

这层里的项目各管一摊:`exposure_scale` 是不入时段表的额外乘子、各时段都压暗;暗角把视线收向画面中心;3D LUT 把一堆离散调色参数换成一张查找表、做整体情绪偏色;辉光让亮处溢光;色差在画面边缘把 R/B 通道错开一两像素;抖动消色带、颗粒加质感。

在裸基线上逐一加这些后期,各自的贡献其实很清楚(下图,每对左裸右加):

![后期四项: 辉光/色差/颗粒/曝光](https://code.leafvmaple.com/assets/hd2d/postfx.png)

但叠进完整画面时,它们都是**温和的全局微调**——单独开关一项不像投影/轮廓那样一眼可辨,而是叠在一起才成立的「底味」。真正几何性的效果(投影、轮廓、景深)对比最强,放在下面几节。

## 二、一个统一光源喂三套影子

影子分三类,机制各异:**精灵方向影**(精灵当前帧的暗色斜切副本)、**结构投影**(墙/楼/树瓦片的整片轮廓沿光向 march)、**接触 AO**(脚下常驻的软暗,不随光向)。前两者必须方向一致,否则一眼假——于是它们读同一个光源。

做法是把太阳定义在**地面(格)平面**上:一个方位角(指向太阳的格空间向量)加一个高度角。一个点 `h` 像素高处的影子位移是 `cell_to_screen(anti-sun) * h * cot(elevation)`——等距视角下「影子贴在斜地面上的透视压缩」由投影本身算出,不需要单独的拍扁 hack。精灵影(2c)和结构影(2d)都从这一个太阳换算各自的投影,方向天然一致,长度只差在各自的高度,物理正确。

精灵影锚在脚底:扫一遍当前帧找最底部不透明像素行作为支点(缓存),这一行钉死,上面的行按 lean 向背光方向倾,于是影子正好从脚接地处长出来,不浮空。

### 掠射太阳把精灵影压成一条线

精灵影是把当前帧做一次 2D 仿射剪切。剪切基的 y 轴 `lean` 的屏幕竖直分量 `lean.y` 正比于太阳方向投到屏幕后的竖直分量。当太阳掠到屏幕水平方向时——格空间里 `sun_cell.x + sun_cell.y → 0`——这个竖直分量趋于 0,剪切矩阵

```text
[ 1    lean.x ]
[ 0    lean.y ]   行列式 = lean.y → 0
```

退化:整个精灵被压成脚底一条 1px 的横线。

结构影(2d)是真的轮廓 march,不会塌;只有精灵的仿射剪切会。修法是给 2c 单独加两道地板:`lean.y` 的绝对值有下限(保留可信的厚度,且强制略微朝前下方落),slope 有上限(极低日时长度不发散)。静态默认太阳不在掠射区,这两道钳不触发,老影子逐像素不变。

![剪切矩阵塌线 vs 防塌钳](https://code.leafvmaple.com/assets/hd2d/shadow_collapse.png)

这个塌线截图反而拍不出来——掠射时塌的影子是脚下一条横线、正好被角色身体压住,加上黄昏暗草地零对比;机制型的问题用几何示意图比游戏截图清楚。正常太阳下精灵投影是这样(裁到角色簇):

![角色投影 关 vs 开](https://code.leafvmaple.com/assets/hd2d/char_shadow.png)

### 结构影是真 march,不会塌

墙、楼、树这类瓦片不走仿射剪切:先把它们渲成一整片轮廓贴图,地面 shader 再沿光向逐步 march、采那张轮廓,投出连贯的硬影。好处是连片建筑不会各投各的、糊成一坨,树投出的是树形。它是真正的轮廓投影,掠射时只是变长,不退化——没有行列式趋零的问题。所以防塌钳只给精灵影(2c)加,结构影(2d)从不需要。

结构影是这套里覆盖面积最大、最一眼可见的一层——关掉它,地面立刻平亮一截:

![结构投影 关 vs 开](https://code.leafvmaple.com/assets/hd2d/struct_shadow.png)

### 接触 AO 把角色坐实

方向投影在太阳高、或方向掠射变淡时会几乎消失,这时角色容易显得悬浮。再叠一层接触 AO:脚下一团常驻的软暗椭圆(平方衰减的软核、压扁成贴地比例、z 排在最底),不随光向变,只把人和物压在地面上。方向影负责「光从哪来」,接触 AO 负责「确实站在地上」,两者职责分开。

## 三、2D 动态光照:环境光、点光、法线

光照是两层叠加。底层是一张 `CanvasModulate` 环境光,给整块画布乘一个随时段变的色——白天近白、夜里偏冷蓝;它本身不发光,只定义「没有光源时世界有多亮、什么色」。上层是 `PointLight2D` 点光(灯笼、火把、主角随身光),在环境光之上把局部提亮。

`PointLight2D` 配 `normal_map` 能让点光照出真正的明暗起伏:灯笼、火把、月光会「裹」在墙面和地面上。给瓦片烤一张法线图挂上去即可。

但紧接着主角脚下的火把光池**直接减半**。原因在自动生成的法线:平均法线并不正对光,`N·L < 1`,于是被法线调制过的地面对同一盏灯的平均响应比纯平面暗。墙面有起伏、值得上法线;地面本就是平的,上了法线只是平白吃掉一截亮度。修法是只给 Building/Overhead 层挂法线,Floor 层保持纯平。

随身光还按环境亮度做**暗度门控**:每帧对当前环境光估一个亮度,越亮越关、越暗越亮——白天灭、黄昏起、夜里满。火把只在该亮的时候亮,既不会在大白天把脸和地面冲过曝,又能在夜里成为唯一光源。光源「什么时候有意义」也被数据化,而不是常亮。

![动态光照: 暗环境光 + 暖点光](https://code.leafvmaple.com/assets/hd2d/lighting.png)

## 四、自定义材质让精灵暗约一成——同一个坑踩了三次

HD-2D 招牌的轮廓背光(rim light):角色背后一道冷蓝描边,把人从背景里切出来。第一版直接把 rim 材质挂在精灵主节点上。结果角色整体比周围暗了一截。

实测:同一精灵,挂任意自定义 `ShaderMaterial` 时采样亮度 55.2 → 49.5,**暗约一成**。`render_mode unshaded` 不解决——它来自「在受光画布里带了材质」这件事本身。这是 gl_compatibility 2D 光照管线的一个怪癖。

修法是把 rim 从主精灵上拿下来,改成一张**加法叠加的副本精灵**:复制当前帧、套 rim 材质、`blend_add`、给一个高 `z_index`。主精灵不再带任何材质,不被压暗;而那个高 z 的叠加层有个意外好处——**它会画在树木之上**,把躲在树冠下的 NPC 也勾出一圈轮廓:

![轮廓背光 关 vs 开](https://code.leafvmaple.com/assets/hd2d/rim.png)

同一个怪癖后来又踩了两次:

- **角色电影分级**(`char_grade`,gamma/对比/饱和):材质工厂在三项全为 1.0 时返回 `null` 而不是「挂一个恒等材质」。因为只要材质还挂着,那一成压暗就还在——把数值调成 1.0 看着「没关干净」,正是这个原因。真正的开关是 `null`。
- **精灵提亮**(`char_brightness`):`self_modulate` 对带自定义材质的精灵无效。于是分两条路——分级**关**时无材质,走 `self_modulate` 干净单调地提亮;分级**开**时由分级 shader 里的 `grade_brightness` 承担。两条等价。

![角色电影分级: gamma 压暗中间调 + 对比 + 饱和](https://code.leafvmaple.com/assets/hd2d/char_grade.png)

## 五、时段、雾、大气与草木

一张随时刻(0~24 时)变化的关键帧表统一驱动调色 + 雾 + 太阳。默认只动后处理调色和雾,绝不动已调好的影子方向;只有显式开 `daynight_sun` 才让太阳(影子)跟着时段走——因为等距视角下太阳必须待在上半球,影子才落向前下方可见。剧情事件用 `set_time_of_day("dusk", 2.0)` 这样的接口平滑切时段。

![切到夜: 统一调色 + 雾 + 太阳一起变冷压暗](https://code.leafvmaple.com/assets/hd2d/night.png)

雾有两种,互补:**距离雾**沿屏幕 Y 往上加浓(等距里越靠上越远),压远景;**贴地冷雾**是 SubViewport 内一张 FBM 噪声层,压下方前景,越夜越浓、白天淡出为 0。两者一上一下,出纵深。

![两种雾互补:上距离雾压远、下地雾压近](https://code.leafvmaple.com/assets/hd2d/two_fog.png)

大气粒子(浮尘/落叶/雪/雨/火星/花瓣)挂在 SubViewport 内,吃同一套调色和辉光,所以夜里不会突兀地跳。粒子和打在镜头玻璃上的落叶是动态的,静态截图看不出,放动图:

![屏幕特效: 大气落叶 + 镜头落叶(动图)](https://code.leafvmaple.com/assets/hd2d/screenfx.gif)

植被还有一层顶点风摇,关键是不能整株平移——那样像滑动而非摇曳。`TileMapLayer` 的 UV 是图集归一化坐标,每种树瓦占图集里一段固定的纵向区间;扫描每种树瓦的不透明像素,把 [区顶、区底、有效底分数] 填进 shader。顶点按自己落在哪段算出瓦内纵向位置,**有效底(树干根部)以下钉死,往树冠顶线性增到满摆**(平方使树干更硬、树冠更软)。树干稳、只树冠晃,相邻的树靠世界坐标错相,不会整片同步摆。

![草木风摇: 只树冠摆、树干钉死(动图)](https://code.leafvmaple.com/assets/hd2d/wind.gif)

移轴景深目前是按屏幕 Y 分带的「假」虚化(下图为开关对比,模糊量稍调强以便看清),真景深要拿格深当深度驱动,留作后续:

## 六、把这些做成可关的开关

效果越堆越多,得能逐项关。最后把全部接进一套开关系统,分三组——场景(光照/风摇/粒子/地雾/镜头落叶)、画面后期(辉光/景深/暗角/色差/颗粒/距离雾/LUT)、角色(投影/轮廓光/分级)——默认全开、即时生效、不重建场景。

实现按效果属主分:后期类把对应 uniform 推成配置值或中性 0(距离雾受时段驱动,故每次时段变化后重新 gate);角色类切子节点显隐或分级材质;场景类切光照可见性、增删子节点。距离雾这种被时段每帧覆盖的,gate 必须放在时段应用之后,否则又被覆盖回来。

## 七、还能往哪走

上面这摞是「现管线里 ROI 最高的一层」——绝大多数是屏幕空间的廉价近似:没有真实几何,所有立体感都靠在 2D 上糊出来。再往上分两个梯度。

### 进阶:现有管线能扩展的

- **体积光 / 神光(god rays)**:屏幕空间径向模糊,从光源向外发散,做树隙、窗棂透出的光柱。纯后处理、不动美术资产,氛围收益大。参考 Ori and the Blind Forest、Hollow Knight。
- **水面反射 + 折射**:把世界对水面镜像做一次二次渲染当反射,叠法线扰动做折射。武侠场景水多,收益直接。参考 Sea of Stars、Eastward。
- **视差多层 + 前景虚焦**:远景按层做视差位移,前景的树枝、草虚化并半透明遮挡镜头,纵深一下就出来。
- **真景深**:现在的移轴是按屏幕 Y 分带的假虚化;等距场景天然带「格深度」,拿它当深度图驱动弥散圆(CoC),才是几何正确的景深。这是「假 → 真」最该补的一道缺口。

### 前沿:要换光照底层的

- **Radiance Cascades**:2023–24 出现的 2D 实时全局光照(Alexander Sannikov,《流放之路 2》在用)。核心是在屏幕上铺多级「辐射度级联」探针——远处高角分辨率、低空间密度,近处反过来——合出软阴影、颜色辉映(红枫把暖色辉映到地面和人身)和真·间接光。这是目前 2D 画质的天花板,社区已有 Godot 实现。
- **SDF + Jump-Flood 光线步进**:把场景烤成有向距离场(用 jump-flooding 快速生成),再 ray-march 出软阴影与局部光照。它是 Radiance Cascades 的轻量前身,也是体积光、水面、动态软阴影可以共用的统一底座。
- **扩散模型离线增图 / 风格迁移**:用生成模型把手绘或占位美术统一风格、并补出法线图与高度图,喂给上面的光照管线。把「美术产能」这个真正的瓶颈从管线里解出来。

### 一条主轴

这些取舍背后是同一件事:**2D 没有真实几何与深度,所有立体感都是在屏幕空间用近似换来的**。越往上走,就越是在把本属于 3D 的东西——全局光照、距离场、深度——以可承受的代价搬进 2D。当前管线停在「廉价近似」这一层:法线给了伪起伏、剪切给了伪投影、移轴给了伪景深、分层给了伪纵深。每一个「伪」都是一道等着被真值替换的缺口。Radiance Cascades 之所以是天花板,是因为它第一次让 2D 的间接光便宜到能实时——把「光照」这一项从近似真正换成了计算。
